# 💈 نظام صالون الحلاقة المتكامل

موقع إلكتروني + نظام حجز مواعيد + متجر إلكتروني + لوحة تحكم كاملة — بلغة **العربية والإنجليزية** (RTL/LTR) وتخصيص كامل من لوحة التحكم.

---

## ✨ المميزات

### الموقع العام
- صفحة رئيسية: واجهة (Hero) + إحصائيات + من نحن + خدمات + مزايا + فريق الحلاقين + معرض أعمال + متجر + آراء العملاء + ساعات العمل والخريطة
- صفحات: الخدمات، الحلاقون، **الحجز أونلاين**، **المتجر**، صفحة منتج، السلة، إتمام الطلب، المعرض، اتصل بنا
- نموذج حجز سريع في الواجهة، خطوات حجز من ٤ مراحل (خدمة ← حلاق ← تاريخ ووقت ← بياناتك)
- تقويم ذكي يعرض الأيام المتاحة فقط + أوقات متاحة حسب **مدة الخدمة، جدول الحلاق، الحجوزات الموجودة، وأوقات الإجازة**
- سلة مشتريات جانبية (تُحفظ تلقائياً) + أكواد خصم + مصاريف شحن وتوصيل مجاني
- تبديل اللغة العربية/الإنجليزية في كل صفحة
- تصميم متجاوب بالكامل (جوال، تابلت، كمبيوتر)

### لوحة التحكم `/admin`
| القسم | ما يمكنك فعله |
|---|---|
| الرئيسية | إحصائيات (مواعيد اليوم، الإيرادات، العملاء، الطلبات الجديدة)، رسم بياني لأسبوع، أحدث الحجوزات والطلبات، أكثر الخدمات طلباً، تنبيه المخزون |
| المواعيد | جدول بكل الحجوزات + تصفية بالتاريخ/الحالة/الحلاق + تغيير الحالة + حجز يدوي + طباعة |
| الخدمات | إضافة/تعديل/حذف: الاسم عربي وإنجليزي، السعر، المدة، التصنيف، الأيقونة، الصورة، الترتيب |
| الحلاقون | البيانات، الصورة، التقييم، الخبرة، **الخدمات التي يقدمها**، **جدول عمل خاص بكل حلاق** |
| المنتجات | كل بيانات المنتج، السعر، سعر قبل الخصم، المخزون، التصنيف، مميز/مخفي |
| الطلبات | عرض الطلبات + تفاصيل المنتجات + تغيير الحالة + التواصل عبر واتساب |
| أكواد الخصم | نسبة مئوية أو مبلغ ثابت + حد أدنى للطلب |
| المعرض / التقييمات / الرسائل | إدارة كاملة |
| **الإشعارات** | سجل كل الرسائل (واتساب/SMS/بريد/تنبيه داخلي)، إرسال يدوي، إعادة المحاولة، تشغيل التذكيرات المجدولة، حذف/تعيين كمقروء، وجرس تنبيهات في الأعلى بعدد غير المقروء |
| **الإعدادات والتخصيص** | الهوية والشعار، **الألوان** (أساسي/ثانوي/خلفية/نص) بمعاينة حية، **الخط**، انحناء الحواف، نصوص الواجهة، **ساعات العمل**، معلومات التواصل وروابط السوشيال، إعدادات الحجز (مدة الفترة، أقصى مدة حجز، التأكيد التلقائي)، إعدادات المتجر (العملة، الشحن، الضريبة) |

## 🔔 نظام الإشعارات

**أحداث تلقائية:**
| الحدث | متى يُرسل |
|---|---|
| تأكيد الحجز | فور إتمام الحجز (موقع أو يدوي من الإدارة) |
| تذكير بالموعد | تلقائياً قبل الموعد بعدد ساعات تختاره (افتراضي ٢٤ ساعة) |
| إلغاء الحجز | عند تغيير حالة الحجز إلى "ملغي" |
| طلب جديد / تحديث حالة الطلب | عند إنشاء الطلب أو تغيير حالته |
| تنبيه إداري داخلي | حجز جديد أو طلب جديد (يظهر في جرس التنبيهات أعلى لوحة التحكم) |

**القنوات والمزوّدون (من الإعدادات ← الإشعارات):**
- **واتساب:** رابط مباشر `wa.me` (يعمل فوراً بدون أي مفاتيح — الإرسال يدوي بضغطة زر) · UltraMsg · CallMeBot · Twilio · Webhook مخصص
- **SMS:** Twilio · Webhook مخصص
- **بريد إلكتروني:** SMTP (جيميل أو أي سيرفر)
- **تنبيه داخلي:** يظهر في لوحة التحكم

**القوالب:** عدّل نص كل رسالة بالعربية والإنجليزية مع متغيرات تلقائية:
`{name} {code} {date} {time} {service} {barber} {price} {salon} {phone} {total} {status}`

**التذكيرات التلقائية:** استدعِ هذا الرابط كل ساعة (cron job / UptimeRobot / cPanel Cron) لإرسال التذكيرات المجدولة:
```
GET https://your-domain.com/api/cron/reminders
```
أو اضغط زر «تشغيل التذكيرات المجدولة» داخل صفحة الإشعارات. يمكنك تأمين الرابط بـ `CRON_SECRET` في ملف `.env`.

## 🚀 التشغيل

```bash
cd barbershop
npm install
cp .env.example .env    # ثم املأ بيانات Supabase (انظر SUPABASE.md)
npm run db:seed         # البيانات التجريبية (بعد تشغيل schema.sql في Supabase)
npm run dev             # http://localhost:3000
```

> 💠 المشروع يتصل **حصرياً بـ Supabase** — أنشئ مشروعاً مجانياً ونفّذ ملف `supabase/schema.sql`
> من SQL Editor، ثم انسخ `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` في `.env`.
> الدليل الكامل خطوة بخطوة في ملف **`SUPABASE.md`**.

### بيانات الدخول للوحة التحكم
```
/admin
البريد:  admin@alsalon.com
كلمة المرور: ********
```

### 👥 المستخدمون والصلاحيات
من لوحة التحكم: **المستخدمون** — أضف حسابات إضافية للإدارة أو للموظفين:

| الدور | الصلاحيات |
|---|---|
| **مالك** (owner) | كل شيء: إضافة/تعديل/حذف المستخدمين، تغيير الصلاحيات، الإعدادات |
| **مدير** (admin) | إدارة العمليات (المواعيد، الخدمات، المنتجات، الطلبات) — بدون إدارة المستخدمين أو الإعدادات |
| **موظف** (staff) | مشاهدة فقط (المواعيد والطلبات) |

- كل حساب له بريد وكلمة سر خاصة، ويمكن تعطيله مؤقتاً دون حذفه.
- لا يمكن حذف المالك أو حذف آخر حساب مالك، ولا يمكن للمستخدم حذف حسابه الحالي.
- عبر سطر الأوامر (للطوارئ): `node scripts/reset-password.mjs كلمة_السر [البريد]`

### 🔑 تغيير كلمة المرور
**من داخل لوحة التحكم (الأسهل):** الإعدادات ← **الحساب والأمان** ← غيّر الاسم/البريد/كلمة المرور.

**عبر سطر الأوامر (إن نسيتها):**
```bash
node scripts/reset-password.mjs كلمة_السر_الجديدة
# أو مع تغيير البريد:
node scripts/reset-password.mjs كلمة_السر_الجديدة admin@alsalon.com
```
> كلمات المرور محفوظة **مشفّرة** (scrypt) في قاعدة البيانات.
> ملف `.env` (`ADMIN_EMAIL` / `ADMIN_PASSWORD`) يُستخدم فقط عند أول إنشاء للحساب.

## 🎨 التخصيص

1. ادخل إلى `/admin` ← **الإعدادات**
2. غيّر الألوان وشاهد المعاينة الحية، بدّل الخط، عدّل نصوص الواجهة، حدّث ساعات العمل وبيانات التواصل
3. احفظ — التغييرات تظهر فوراً على الموقع

كل عناصر الموقع (الخدمات، الحلاقون، المنتجات، المعرض، التقييمات) تُدار من لوحة التحكم بدون كتابة كود.
لرفع صورة: استخدم حقل الصورة في أي نموذج ← زر "رفع" (تُحفظ في **Supabase Storage** — حاوية `uploads` العامة، وتُحفظ محلياً في التطوير كاحتياط).

## 🧱 التقنيات والبنية

- **Next.js 15** (App Router) + React 19
- **Supabase فقط**: قاعدة بيانات PostgreSQL + تخزين الصور (Supabase Storage) عبر مكتبة `@supabase/supabase-js` الرسمية — لا Prisma ولا أي قاعدة أخرى
- CSS مخصص بالكامل مع متغيرات CSS (`--primary`, `--bg`, ...) تُدار من قاعدة البيانات
- مصادقة بجلسة توقيعية (HMAC) + كلمات مرور مُشفّرة بـ scrypt

```
src/
  app/
    [locale]/          صفحات الموقع (ar | en)
    admin/(dash)/      لوحة التحكم
    api/
      public/          الحجز، الأوقات، الطلبات، الخصومات، التواصل
      admin/           CRUD عام + إعدادات + رفع صور + إحصائيات
  components/          مكوّنات الواجهة + مكوّنات الإدارة
  lib/                 supabase (الاتصال والاستعلامات), auth, i18n, settings, slots
supabase/
  schema.sql           إنشاء الجداول (يُنفَّذ من SQL Editor)
  seed.mjs             البيانات التجريبية
public/uploads/        الصور
```

## 🔧 ملاحظات إضافية

- **زر إعادة البيانات التجريبية** موجود في أعلى صفحة الإعدادات (يعيد تعبئة كل الجداول).
- نظام المواعيد يمنع الحجز المزدوج تلقائياً ويتحقق من التوفر قبل التأكيد.
- يمكن إضافة حلاق بجدول عمل مستقل عن الصالون، وتحديد أوقات إجازة لكل حلاق.
- للإنتاج: `npm run build && npm start`، ويفضّل تغيير `SESSION_SECRET` في `.env`.
